# Выбор маршрутов и компактное сравнение — 5 октября 2026

Пользователь выбирает банки до анализа. Новый сеанс выбирает первые два маршрута; выбор сохраняется локально по ID сеанса и восстанавливается, включая пустой выбор. Сервер получает только выбранные route IDs и по-прежнему загружает собственные требования. Снятие выбора не меняет сохранённые требования/approval; существующие пакеты остаются доступными до следующего анализа.

Таблица сравнения показывает канал, статус чеклиста, число missing/uncertain и ограничения применимости. Неанализированные маршруты не получают искусственный статус готовности. Изменения профиля/evidence показывают необходимость пересчёта вместо старых счётчиков. Полные требования/источники и строки пакетов раскрываются отдельно. Политика банка и approval не изменялись. Экспорт/follow-up предлагают только подготовленные маршруты. На мобильном таблица прокручивается внутри своей области, страница не переполняется.

Проверки: 133/133 автоматических теста и 26/26 прежних офлайн-кейсов. Прежний браузерный E2E и новый E2E сравнения проходят: payload только выбранных банков, пустой выбор, reload, stale results, раскрытие списков, мобильный overflow, отсутствие ошибок страницы. Просмотрены desktop/mobile screenshots. Детектор оформления работает в ограниченном regex-режиме; замечание о существующем Inter не меняет визуальную идентичность проекта, вычисляемый контраст им не проверялся. Реальные API повторно для этого изменения не вызывались; live E2E обновлён для явного выбора всех пяти маршрутов, но его новый запуск не выполнен.

Следующий этап готовности: полный review банковского демонстрационного сценария и разрешение Qonto 5%; внешний просмотр пользователями, расходы/лимиты, публичный хост и видео. Все ограничения новых банков из bank-expansion-2026-10-04.md сохраняются. Деплой/Devpost не выполнены.
